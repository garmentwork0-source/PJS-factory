# PJS Garment Management System
Responsive starter web app for Android, tablets and desktop.

## Run
Extract the ZIP and open `index.html` for a local test. For installable PWA/offline support, host the folder on an HTTPS static host, open the URL in Chrome on Android, then choose **Add to Home screen** or **Install app**.

## Modules
Dashboard; Sales & Billing; Customer Ledger; Sales Returns; Finished Goods Stock (PCs); Worker PC Rate Ledger; Staff Monthly Salary; Combined Cash + Bank Daily Record; Reports and JSON backup/restore; browser print / Save PDF.

## Important
This is a starter MVP, not yet a deployed cloud service. Data is stored in the browser on this device and does not sync between devices. Before live multi-user use, add secure login, server database, role permissions, audit trail, tested backup/restore and accountant review. Test all workflows with sample data before entering actual accounts.
